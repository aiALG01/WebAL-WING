# Bilder für die Referenzen (projekte.html)

Hier die Screenshots ablegen — genau mit diesen Dateinamen, dann erscheinen
sie automatisch auf `projekte.html`:

| Datei | Inhalt | Empfohlene Größe |
|---|---|---|
| `tsv-alt-desktop.webp` | Alte Jimdo-Seite, ganze Startseite am Desktop | 1440 px breit |
| `tsv-neu-desktop.webp` | Neue Seite, ganze Startseite am Desktop | 1440 px breit |
| `tsv-alt-mobil.webp` | Alte Seite am Handy | 780 px breit |
| `tsv-neu-mobil.webp` | Neue Seite am Handy | 780 px breit |
| `galoppal-desktop.webp` | galoppal.de am Desktop | 1440 px breit |
| `galoppal-mobil.webp` | galoppal.de am Handy | 780 px breit |

Hinweise:

- **Ganzseiten-Screenshots** (die ganze Seite von oben bis unten) — das
  Fenster auf der Website ist scrollbar.
- Für den Vorher/Nachher-Slider sollten **alt und neu jeweils gleich breit**
  sein (beide 1440 px bzw. beide 780 px), sonst passen sie nicht übereinander.
- Format **WebP** (Qualität ca. 80) hält die Dateien klein. Wenn du nur
  PNG/JPG hast: entweder konvertieren (z. B. squoosh.app) oder in
  `projekte.html` die Endung `.webp` im `src` und in `data-desktop` /
  `data-mobil` anpassen.
